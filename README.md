# RAG-based-chatbot-langchain-huggingface-faiss
RAG-based chatbot using LangChain, Hugging Face, OpenAI and FAISS.

## Project Overview
This project explores Retrieval-Augmented Generation (RAG) to build AI-powered chatbots that retrieve relevant information and generate context-aware responses.

## Technologies Used
- Python
- LangChain
- Hugging Face
- OpenAI API
- FAISS
- Jupyter Notebook

## Project Notebooks
1. **Lang.ipynb** – LangChain-based implementation.
2. **hugging.ipynb** – Hugging Face integration.
3. **openai-langchain.ipynb** – LangChain with OpenAI.

## Key Concepts
- Large Language Models (LLMs)
- Retrieval-Augmented Generation (RAG)
- Vector Embeddings
- Vector Database
- Semantic Search
- Prompt Engineering

## How to Run
1. Clone this repository.
2. Install the required Python libraries.
3. Configure the required API keys securely.
4. Open the notebooks using Jupyter Notebook or Google Colab.
5. Run the cells sequentially.
